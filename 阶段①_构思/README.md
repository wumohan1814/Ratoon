# 阶段① 构思（模块骨架）

> **何时启用**：项目还没蓝图时（新项目第一天），或用户说"我想先想清楚"。
> **何时退出**：蓝图被用户确认 → **Agent 建议进入阶段②**（`01` §0 阶段路由）。

---

## 加载规则（**重要**）

- **只加载本模块 + 共享核心**；**不加载** `阶段③_收尾/`（阶段之间互不加载——避免"想太多"导致幻觉与 token 膨胀）
- **共享核心**（三阶段都要）：`00_协议.md` · `00_根/` 结构 · `库/`

---

## 本模块管什么

| 管 | 不管（属别的阶段） |
|---|---|
| 想清楚要做什么、给谁用、第一步做什么 | 一节一节做（阶段②） |
| **可选深度调研**：同款/竞品/参考产品的"样子" | 交付前检查与发布（阶段③） |
| 定方向的三件套（技术栈 / 目录 / 数据方案）→ **Agent 提方案（大白话 + 后果）+ 建议，用户拍板** | —— |
| 蓝图（用户唯一必须亲自把关的一页） | —— |

**⚠️ 技术选型由 Agent 提方案（大白话 + 各选项后果）+ 建议，用户拍板**（见 `02` §7.2）。

**⛔ 边界（用户明确）**：本阶段**只帮用户把想法细化、落地、变成可执行的项目**——
**不涉及商业化**：不做商业计划、不算市场规模、不帮拉投资、不写营销方案。
**判断依据**：破竹管的是「**把想法变成可执行的项目**」，不管「把它变成生意」。
