# errcode-http-mapping

> 版本：v1.0 ｜ 状态：待命中

## 一句话
中文业务错误码按段映射 HTTP 状态的约定；断言「资源不存在」按 body code，不按 REST 直觉。

## 不解决什么（边界）
- 不规定具体错误码编号（各项目自定 1xxx 内的细分码）
- 不规定错误信封 JSON 结构
- 不适用于无业务错误码的纯 REST 项目

## 契约（用之前必须知道的）
- 怎么调用：见 `约定.md` 的映射表
- 依赖什么：无
- 什么绝对不能改：段↔HTTP 映射关系（1xxx→400 / 2xxx→401,403 / 3xxx→404 / 4xxx→422 / 5xxx→502）

## 用过的项目
**见 `库/索引.md`**（唯一记录处——此处不重复，防漂移）

## 已知限制 / 坑
- 3xxx（资源不存在）才是 404；通用不存在（1xxx·1002）是 400——别混
- 断言一律按 body `code`，别按 HTTP 直觉（那只在 3xxx 段成立）
