# 错误码分段 ↔ HTTP 状态映射约定

| 段 | 语义 | HTTP | 例 |
|---|---|---|---|
| 1xxx 通用 | 通用 / 参数 / 不存在 | 400 | ERR_NOT_FOUND=1002 → 400 |
| 2xxx 认证鉴权 | 登录 / 权限 | 401 / 403 | — |
| 3xxx 资源 | case / 档案等资源不存在 | 404 | case 不存在 |
| 4xxx 计算 | 排盘 / 计算输入 | 422 | — |
| 5xxx 服务 / LLM / 积分 | 上游 / 余额 | 502 | 5002 余额不足 |

## 断言规则

- 「资源不存在」按 body `code` 判断（如 `resp.json()["code"] == 1002`）
- 不要按 REST 直觉断言 HTTP 404——那只在 3xxx 资源段成立
