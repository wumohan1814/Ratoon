# DSH 测试沙箱已知坑（勿重复踩）

| 现象 | 根因 / 规则 | 落地检查项 |
|---|---|---|
| pytest 报 sqlite3 unable to open database file | conftest 用 tempfile.mkdtemp() 建 0o700 临时目录，workspace-write 沙箱拒绝在其中建 SQLite 文件 | pytest 须在 danger-full-access 下执行 |
| ESM-only 包 require.resolve 误报 MISSING | exports 只提供 import，CJS require.resolve 探测失败 | 用 import(pathToFileURL(...)) 探测 |

| 测试「单跑绿、混跑红」 | 模块级单例配置被收集顺序定格；模块顶层 os.environ 注入受影响 | 用 autouse fixture + monkeypatch.setattr(settings, ...) 注入 |
