# deploy-verification-chain

> 版本：v1.0 ｜ 状态：待命中

## 一句话
Web 服务部署后的验证链：health + 页面 200 + 关键接口冒烟 + 进程无重启循环 + 线上 commit 核对。

## 不解决什么（边界）
- 不规定部署方式（Docker / K8s / 裸进程自定）
- 不覆盖数据迁移验证

## 契约（用之前必须知道的）
- 怎么调用：见 `工作流.md` 的清单
- 依赖什么：无
- 什么绝对不能改：五项验证缺一不可

## 用过的项目
**见 `库/索引.md`**（唯一记录处——此处不重复，防漂移）

## 已知限制 / 坑
- health 通过 ≠ 业务可用，必须补关键接口冒烟
- 「线上 commit = 最新 commit」需要能查线上版本的方式（镜像 tag / 部署脚本产物）
